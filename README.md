# Eisenhower Task Tracker V1

A task management application based on the **Eisenhower Matrix**, built with Node.js, HTML, CSS, EJS and JavaScript.

## Features

- Classify tasks into four categories:
  - Urgent & Important
  - Not Urgent & Important
  - Urgent & Not Important
  - Not Urgent & Not Important

- Create multiple spaces for separate task lists
- Add tasks with:
  - Task
  - Deadline
  - Category

- Manage tasks across different spaces

## Tech Stack

- Node.js
- HTML5
- CSS3
- EJS
- JavaScript

## Run Locally

```bash
npm install
npm start
```

Then open the local server URL in your browser.
